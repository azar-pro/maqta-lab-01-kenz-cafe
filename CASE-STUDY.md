# Kenz Café — Case Study

## Challenge
Create a premium café website that feels contemporary and editorial while keeping a warm Moroccan character. The project had to work as a realistic freelance portfolio piece rather than a generic template.

## Direction
A restrained visual system built around warm ivory, deep charcoal, coffee-brown details, elegant serif typography and immersive café photography. The interface uses generous spacing, simple navigation and strong typography to keep the experience calm and premium.

## Build
The website was built from scratch with semantic HTML5, CSS Grid/Flexbox and vanilla JavaScript. It includes five responsive pages, full-screen mobile navigation, interactive menu tabs, a front-end booking-form demo, keyboard accessibility, responsive layouts and a custom Kenz Café identity.

## Technical work
- Semantic HTML and responsive CSS
- Vanilla JavaScript interactions
- Accessible keyboard navigation and visible focus states
- Client-side form validation with accessible errors
- Canonical URLs and page-specific metadata
- Open Graph and Twitter sharing metadata
- robots.txt and sitemap.xml
- SVG favicon
- Hero image preloading and origin preconnects
- Reduced-motion support

## Applications
- Home page
- Our Story page
- Menu page
- Gallery page
- Visit / booking page
- Desktop, tablet and mobile layouts

## Result
A complete fictional specialty-coffee website suitable for a front-end portfolio case study and for demonstrating custom HTML, CSS and JavaScript website development to prospective freelance clients.

> Kenz Café is a fictional portfolio concept. Contact details, pricing and reservation behavior are demonstration content.
